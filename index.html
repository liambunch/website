> About Me

Hi, I’m Liam, also known online as Watire. I’m an 18-year-old IT support tech based in Sydney, currently studying a Certificate IV and a Diploma of Information Technology. At the moment, I’m obsessing over declarative configuration (NixOS, k8s with Flux, etc).

My current main project is called Bunch Webhost, a homelab built from six old office PCs running NixOS and Kubernetes (k3s), with everything declared in Git and automatically deployed via Flux. It exists so I can learn how real infrastructure works by actually running it, and it hosts sites for other people too. I love declarative configuration because I hate configuring things and then forgetting what I set up.
